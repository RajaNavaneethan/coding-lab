Subsets

LeetCode 78 · Medium · Pattern: backtracking (choose / skip) · O(n · 2n) time, O(n) extra space

Problem. Given an array of distinct integers nums, return all possible subsets (the power set). The answer may be in any order and must not contain duplicate subsets.
nums = [1,2,3] → [[],[1],[2],[3],[1,2],[1,3],[2,3],[1,2,3]]    nums = [0] → [[],[0]]
Link: LeetCode

1. The one idea that solves it

Walk the array left to right. For each element, make a binary choice: skip it or include it. A full walk from index 0 to n produces one subset. The complete set of walks is a binary tree of depth n, and its 2n leaves are the subsets you need.

The engine is backtracking: push the element before you recurse, pop it after. That way the same vector cur is reused for every walk, and the "unchoose" step undoes the last push so the next walk starts clean.

Idea. For each index, branch into two children: skip or include. The leaves of this binary tree are the subsets. Backtracking (push on the way down, pop on the way up) explores every leaf while reusing one vector.

2. Picture of the algorithm

The recursion at index i does two things: first recurse without nums[i], then push it and recurse again. On the way back up, pop so the next branch sees a clean cur.

4. Code (C++)

class Solution {
public:
    vector<vector<int>> subsets(vector<int>& nums) {
        vector<vector<int>> ans;
        vector<int> cur;
        function<void(int)> dfs = [&](int i) {
            if (i == (int)nums.size()) { ans.push_back(cur); return; }
            dfs(i + 1);                     // skip nums[i]
            cur.push_back(nums[i]);         // include nums[i]
            dfs(i + 1);
            cur.pop_back();                 // unchoose
        };
        dfs(0);
        return ans;
    }
};

Complexity: there are 2n subsets and each is copied into ans in O(n), so O(n · 2n) time. Extra space is O(n) for the recursion depth and cur; the output itself is O(n · 2n).

Alternative: the "for-loop" form

void dfs(int start, vector<int>& nums,
         vector<int>& cur, vector<vector<int>>& ans) {
    ans.push_back(cur);                 // every node is a subset
    for (int i = start; i < (int)nums.size(); i++) {
        cur.push_back(nums[i]);
        dfs(i + 1, nums, cur, ans);
        cur.pop_back();
    }
}

Same answers, different shape of tree: here every node (not just the leaf) is a subset, and the fan-out is "pick the next element to add". Use the choose/skip form when you want to see the binary structure clearly, and the for-loop form when the children at a node are naturally a range of choices (combinations, combination sum).

5. The part interviewers ask about: order and no duplicates

Two things come up most often:

No subset appears twice because at each index we take exactly one of two paths. Different leaves differ in at least one choice, so they produce different index sets, so they produce different subsets (the input values are distinct).

The empty subset is included because the first thing the recursion does is skip index 0, then skip 1, ..., all the way down. That walk never pushes anything, so when i == n the empty cur is copied into ans.

If the problem had duplicates (LC 90 Subsets II), the two-child view would create duplicate subsets. The fix is the for-loop form plus "at each level, skip over duplicates of the just-tried value": sort first, then if (i > start && nums[i] == nums[i-1]) continue;.

6. Traps and edge cases

  • Forgetting the pop. If you push and recurse but never pop_back, the sibling branch sees the element still inside cur. All subsets on that branch will be wrong.
  • Pushing a reference instead of a copy into ans. ans.push_back(cur) is a copy and is correct. If you store a pointer or reference, every entry will show the final state of cur.
  • Empty input. nums = [] must return [[]], not []. The recursion handles it: index 0 is already the base case, so one empty subset is emitted.
  • Single element. nums = [0] → [[],[0]]. Easy to forget the empty subset.
  • n up to 10 on LeetCode. 210 = 1024, so even bit-mask enumeration works, but backtracking is the standard answer because it generalises to the other subset-style problems.

7. How to say it in the interview (30 seconds)

"At each index I have two choices: skip the element or include it. That is a binary recursion of depth n, so 2n leaves, one per subset. I use one shared vector cur and backtrack: push before recursing with "include", pop after. At the base case I copy cur into the answer. The empty subset falls out naturally from the all-skip path. Time is O(n · 2n) because I copy each subset, space O(n) for the recursion."
