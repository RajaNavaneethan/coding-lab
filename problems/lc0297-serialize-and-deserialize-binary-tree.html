Serialize and Deserialize Binary Tree

LeetCode 297 · Hard · Pattern: preorder DFS with null markers · O(n) time, O(n) space

Problem. Encode a binary tree into a string, then decode that string back into the same tree. The two must round trip: deserialize(serialize(root)) is structurally equal to root.
[1,2,3,null,null,4,5] → "1,2,N,N,3,4,N,N,5,N,N,"
Link: LeetCode

1. The one idea that solves it

A preorder walk (root, then left, then right) names every node in a fixed order. If you also emit a sentinel every time you walk off a null edge, the sequence becomes unambiguous: the decoder reads one token at a time and knows exactly when a subtree ends.

So the encoding is just: write the value, write the left subtree, write the right subtree. null becomes N. The decoder mirrors it: read the next token, build the node, recurse for its left child, recurse for its right child. The recursion itself defines where a subtree ends.

Idea. Preorder + explicit nulls. On encode, every call writes exactly one token (a value or N); on decode, every call consumes exactly one token. The two shapes mirror each other, so the round trip is automatic.

4. Code (C++)

class Codec {
public:
    string serialize(TreeNode* root) {
        string s;
        function<void(TreeNode*)> dfs = [&](TreeNode* n) {
            if (!n) { s += "N,"; return; }
            s += to_string(n->val) + ",";
            dfs(n->left);
            dfs(n->right);
        };
        dfs(root);
        return s;
    }
    TreeNode* deserialize(string data) {
        int i = 0;
        function<TreeNode*()> dfs = [&]() -> TreeNode* {
            int j = (int)data.find(',', i);
            string tok = data.substr(i, j - i);
            i = j + 1;
            if (tok == "N") return nullptr;
            TreeNode* n = new TreeNode(stoi(tok));
            n->left  = dfs();
            n->right = dfs();
            return n;
        };
        return dfs();
    }
};

Complexity: each node emits/consumes one token plus two null tokens. Total tokens ≤ 2n + 1, so O(n) time and O(n) space for both the string and the recursion stack (at depth h).

Alternative: BFS with null markers

// serialize: level order, emit "N" for missing children.
string serialize(TreeNode* root) {
    if (!root) return "";
    string s;
    queue<TreeNode*> q; q.push(root);
    while (!q.empty()) {
        TreeNode* n = q.front(); q.pop();
        if (!n) { s += "N,"; continue; }
        s += to_string(n->val) + ",";
        q.push(n->left); q.push(n->right);
    }
    return s;
}

This matches the LeetCode visual notation ([1,2,3,null,null,4,5]) exactly, which is handy for debugging. The deserialize mirror uses a queue of parents whose next two tokens are their children. Same O(n). Preorder is more common because the recursion is a tiny self-contained function; BFS needs the explicit queue on both sides.

5. The part interviewers ask about: why nulls are mandatory

Without null markers the preorder sequence is ambiguous. Both [1,2] (1 with left child 2) and [1,null,2] (1 with right child 2) emit the same preorder "1,2". You either need a second traversal (inorder) to disambiguate — that's LC 105 "Construct from preorder+inorder" — or an explicit null marker so each subtree knows where it ends. The marker approach costs one extra token per missing edge; the two-traversal approach costs the entire inorder sequence. Null markers win on size and are easier to decode.

Edge detail: the format must handle negative values and multi-digit values. Delimit tokens with a non-digit character (comma, space). Don't use a fixed width or a non-delimited concatenation. The reference code above splits on commas, so -1024 and 7 are both self-delimited.

6. Traps and edge cases

  • Forgetting the terminator comma. If the last token has no trailing comma, the parser might read past the end. Simplest fix: always emit val, and N, so the comma count equals the token count.
  • Using space or no delimiter. Then 12 and 1 2 collide. Pick a non-digit, non-sign delimiter and stick to it.
  • Empty tree. serialize(nullptr) must round-trip. The code emits "N,", and deserialize reads "N" and returns nullptr.
  • Negative integers. Make sure the number parser accepts a leading -. stoi does.
  • Advancing the input pointer by value. If you don't share i between the two recursive calls, the right child reads the left child's tokens. The lambda captures i by reference, which is the whole point of this shape.
  • Stack overflow on skewed input. A chain of 10000 nodes blows the default stack. For production code, use an explicit stack or BFS. In an interview, mention it.

7. How to say it in the interview (30 seconds)

"I preorder-DFS the tree. At each node I emit its value; at each null edge I emit a sentinel like N, with commas in between. The decoder is the exact mirror: read a token, if it's N return null, otherwise build a node and recurse for its left then right. The null markers remove the ambiguity between a missing left and a missing right child. One pass each way, O(n) time, O(n) space."
